# Локальные модели

Настоящему инференсу одновременно нужны:

| Файл | Назначение |
| --- | --- |
| `yolov8n-face.pt` | Совместимый YOLO-детектор лиц из доверенного источника |
| `arcface_model.pth` | `state_dict` класса `ml.models.FaceClassifier`, эмбеддинг 512 |
| `classes.json` | Объект вида `{"0": "participant_01", "1": "participant_02"}` |

Индексы классов начинаются с 0 и идут без пропусков; нужны минимум два класса. Модель и метки экспортируются одним запуском обучения. Перед их заменой остановите сервер: каждый файл заменяется отдельно, атомарной замены всей тройки нет.

Веса не распространяются с проектом. Демонстрационный интерфейс работает без них. Содержимое папки, кроме README, игнорируется Git.

[Обучение и проверенная загрузка детектора](../docs/training.md#детектор-лиц).
