# Ограничения эксперимента

## Качество

Распознавание здесь — классификация среди меток обучения. Порог по максимальному softmax позволяет вернуть `unknown`, но не даёт гарантии отклонения неизвестных лиц. Для заявлений об open-set качестве нужны отдельные неизвестные классы, выбор порога на validation, независимый test и метрики ошибок принятия/отклонения. В проекте такого подтверждённого измерения нет.

Не реализованы выравнивание по ключевым точкам, проверка качества кропа, галерея эмбеддингов, поиск по базе, видеопоток и liveness. Освещение, ракурс, размытие и сдвиг распределения данных влияют на результат. Границы применимости нельзя выводить из одного красивого примера.

## Данные

Разбиение выполняется внутри каждой метки: одни и те же классы присутствуют в train/val/test. Точные дубликаты отбрасываются по декодированным RGB-пикселям. Похожие кадры, уменьшенные копии и фотографии одной сессии этим не исключаются. Для содержательной оценки подготовьте вручную разбиение по сессиям/источникам и передайте `--splits`.

Классы исходной задачи должны означать конкретные категории вашего эксперимента. Скрипты не смешивают датасеты с несовместимой разметкой; исходные папки с разметкой пола не превращаются в метки личности автоматически.

## Исполнение

API предназначен для локального учебного запуска: нет аутентификации, очереди заданий и распределённых лимитов. В памяти одновременно находятся модели и декодированное изображение. Multipart-загрузчик может временно использовать диск; приложение не создаёт постоянный архив загруженных HTTP-файлов. CLI сохраняет результаты и журнал явно.

Модели загружаются из локальных доверенных файлов. `torch.load(..., weights_only=True)` используется для собственного state_dict; YOLO `.pt` может содержать исполняемые pickle-объекты. SHA-256 проверяет совпадение с ожидаемым файлом, но не делает неизвестный источник доверенным.

Зафиксированы прямые зависимости, но не вся транзитивная среда и системные библиотеки. Seed стабилизирует эксперимент в сопоставимой среде; побитовая идентичность между CPU/GPU, ОС и версиями библиотек не заявляется.
