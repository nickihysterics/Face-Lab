Face Lab 1.0.0 — учебно-демонстрационная лаборатория компьютерного зрения.

- Обновлённый адаптивный интерфейс и синтетический пример, доступный без весов и PyTorch.
- Локальный API с проверкой изображений, лимитами и понятными ошибками.
- Подготовка данных с проверкой дубликатов и воспроизводимым разбиением.
- Исправленная валидация ArcFace без передачи целевой метки; оценка лучшего checkpoint на test.
- Полный синтетический цикл обучения, регрессионные и браузерные проверки, лёгкий Docker-образ.
- README, снимки интерфейса, учебный ноутбук и руководства по архитектуре, данным и моделям.

Архив содержит исходники. Фотографии людей, датасеты и веса не включены. Демонстрационные оценки заданы заранее; качество распознавания реальных лиц в этом релизе не измерялось. Для настоящего инференса подключите собственный классификатор и доверенный совместимый детектор по README.
