# Архитектура

Браузер получает статические HTML/CSS/JS из FastAPI. Демонстрационный маршрут читает только пример; он не импортирует ML-модули. Поэтому базовая установка не требует PyTorch.

```text
Файл → лимит запроса → декодирование / EXIF → проверка моделей
     → YOLO: рамки лиц (не более 32)
     → кроп из исходного изображения + отступ 10 px
     → resize 112×112 → RGB-нормализация
     → ResNet-50 → 512 признаков → нормированная классификационная голова
     → softmax → порог unknown → рамки на отдельной копии → JSON / JPEG
```

При обучении ArcFace добавляет угловой отступ к целевому классу. При валидации, тесте и инференсе используется `FaceClassifier.classify`: только признаки, веса классов и масштаб, без метки и отступа. Выбор лучшего checkpoint выполняется по validation accuracy; затем он повторно загружается перед оценкой test.

Синхронные обработчики инференса выполняются в рабочем потоке FastAPI. Один процесс принимает только один инференс одновременно; занятый возвращает `429`. Внутренний `RLock` защищает загрузку и использование общей пары моделей. Ключ кэша включает устройство, абсолютные пути, размер и время изменения файлов. Для предсказуемого обновления всё равно перезапускайте сервер.

## Контракт API

`POST /api/predict/` и `/api/predict_json/` принимают multipart:

| Поле | Тип | По умолчанию |
| --- | --- | --- |
| `file` | Обязательный JPEG, PNG или WebP | — |
| `conf` | Конечное число 0…1, порог детектора | 0.25 |
| `unknown_threshold` | Конечное число 0…1, порог оценки класса | 0.5 |

Упрощённый пример ответа настоящего инференса, **не измерение качества**:

```json
{
  "mode": "inference",
  "predictions": ["participant_01 (0.92)"],
  "detections": [{
    "x1": 180, "y1": 95, "x2": 355, "y2": 295,
    "label": "participant_01", "conf": 0.92, "detector_conf": 0.96
  }]
}
```

`conf` в детекции — softmax-оценка выбранного класса; `detector_conf` — оценка YOLO. Координаты ограничены размерами RGB-изображения после EXIF-поворота. `/api/predict/` дополнительно содержит `image_base64` и `image_format: jpeg`. При отсутствии лиц оба списка пусты, статус `200`. `/api/demo/` имеет `mode: demo`, пояснение `notice` и SVG вместо JPEG.

| Код | Значение |
| --- | --- |
| 400 | Повреждённое, пустое, неподдерживаемое или слишком большое по пикселям изображение |
| 413 | Файл больше 8 МиБ или всё multipart-тело больше 8 МиБ + 64 КиБ |
| 422 | Нет обязательного поля или порог неверен, включая NaN/Infinity |
| 429 | Другой инференс уже выполняется |
| 503 | Не хватает файлов моделей или ML-зависимостей |
| 500 | Ошибка загрузки/совместимости моделей или инференса; детали в журнале сервера |

Ошибки приложения имеют поле `error`. Непредвиденные ошибки сервера могут возвращать стандартный ответ `500`. API-ответы помечаются `Cache-Control: no-store`. Совместимость весов проверяется при первом реальном вызове; `/api/status/` сообщает только о наличии файлов и пакетов.

## Конфигурация

| Переменная | По умолчанию |
| --- | --- |
| `DATASET_DIR` | `datasets` относительно корня проекта |
| `MODELS_DIR` | `models` относительно корня проекта |
| `REPORTS_DIR` | `reports` относительно корня проекта |
| `FACE_LAB_DEVICE` | `auto`: CUDA, если доступна, иначе CPU |

Абсолютные пути поддерживаются. Относительные значения путей конфигурации разрешаются от корня проекта. CLI-пути разрешаются от рабочей папки. MPS автоматически не выбирается. Для локального запуска оставляйте один worker; несколько процессов независимо загрузят модели и получат отдельные блокировки.

Фронтенд отменяет устаревшие запросы, не показывает старые результаты после смены файла и создаёт текстовые узлы для меток. Через 120 секунд ожидание в браузере прекращается; это не прерывает уже начатое вычисление на сервере.
