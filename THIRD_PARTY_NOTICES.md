# Сторонние компоненты

Публикация содержит собственные исходники проекта, синтетический пример и инструкции. Пакеты устанавливаются отдельно; сторонние датасеты и веса в архив не включены. Условия конкретных пакетов следует смотреть в их установленной версии.

| Компонент / материал | Источник |
| --- | --- |
| FastAPI | https://github.com/fastapi/fastapi |
| Uvicorn | https://github.com/Kludex/uvicorn |
| Pillow | https://github.com/python-pillow/Pillow |
| PyTorch / torchvision | https://github.com/pytorch/pytorch · https://github.com/pytorch/vision |
| Ultralytics | https://github.com/ultralytics/ultralytics |
| Возможный источник YOLO face weights | https://github.com/lindevs/yolov8-face |
| ArcFace, Deng et al. | https://arxiv.org/abs/1801.07698 |

Ultralytics публикует [условия AGPL-3.0](https://www.ultralytics.com/legal/agpl-3-0-software-license); при использовании этого компонента нужно учитывать его лицензию. Ссылка на проект детектора не означает, что любые его веса можно распространять под условиями Face Lab.
