# Локальные данные

В публикацию не включены фотографии людей и сторонние датасеты. Кладите разрешённые для своего эксперимента кропы в `faces/<метка>/<файл>.jpg`. Содержимое этой папки, кроме README, игнорируется Git.

`python scripts/create_demo_dataset.py` создаёт `datasets/synthetic/` с геометрическими фигурами. Это тестовые данные для проверки кода; детектор лиц на них не проверяется. Скрипт откажется перезаписать непустую папку.

[Форматы, подготовка и разделение выборки](../docs/training.md).
